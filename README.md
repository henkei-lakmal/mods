# mods

Claude Code mods.

| Mod | What it does |
| --- | --- |
| [devops-consumption](devops-consumption/) | A pane tracking GitLab compute minutes, storage and seats, Azure DevOps pipeline minutes, parallel jobs and licenses, and the merge and pull requests awaiting your review |

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install devops-consumption --marketplace henkei-lakmal/mods
```

From a shell:

```
claude plugin install devops-consumption --marketplace henkei-lakmal/mods
```

In the Claude desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `henkei-lakmal/mods`, then **Add plugin**.

Answer `y` to add the marketplace, then pick the scope. See the mod's own README for the setup it needs and its settings.
